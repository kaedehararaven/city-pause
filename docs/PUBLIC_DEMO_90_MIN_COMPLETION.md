# 90 分钟公开离线案例补全

## 范围

仅补采真实公开地点和步行路线，更新离线 replay。正式 Candidate Supply、S/M/W、排序、Family、dwell、时间门槛、单地点算法未变。没有用户定位、Place Detail、返程请求，也没有 commit/push。

## 采集过程与成本

- 原公开起点附近：3 次圆形 Search，每次一页20条、半径1500米。休息使用书咖/书店/甜品店/公园，散步使用公园/商业街/购物中心/美术馆，探索使用书店/商业街/美术馆/手工制作。均为当前 Goal 已有 S/M 搜索词，W 仅自然返回保留。
- 三组分别保留16/13/14条验证且去重、每完整标签上限5的候选。合入旧池后再次按标签限额，不把关键词直接当分类。
- 补12条去程、18条原区域站间路线；原起点90分钟休息得到2条，另两类仍受真实路程限制。
- 复用已有 POI 和分类，分别以真实南池子美术馆、王府井商业街坐标检查紧凑案例，各新增18次步行请求。未新搜地点，未从名称猜坐标。
- 合计本轮 Search 3 次、walking 66 次、Detail 0 次。每个采集阶段固定上限，成功真实响应持久化，不伪造缺失边、不逆用有向边。

采集文件：`public-nearby-capture.json`（新POI及去程）、`public-multi-capture.json`（原区域站间边累计52条）、`public-compact-capture.json`（南池子18条）、`public-wangfujing-capture.json`（王府井18条）。原始`public-capture.json`保持不变。部分辅助边不一定进入最终展示，这是可行性验证的正常损耗。
