## 功能

现有 Place v3 scope=2 请求新增适配 brand、navi_location、children，并将已有 price/best_time/detail_url 贯通到 canonical MapPOI 与 UI。具体字段见 CONTRACTS.md。

价格保留原文，无单位时不擅自补人民币/人均/门票。最佳游玩时间保留季节或时间描述。详情链接仅允许官方网页并升级 HTTPS；相关安全校验覆盖恶意 scheme、伪子域、账号密码、凭证参数及 API 路径误用。

子地点最多 20 个，按真实标识去重；只保留白名单字段，不泄漏原始响应。入口信息来自 Provider 名称与分类，不人工推断。导航引导点独立于地点中心；可在小地图查看它和子地点位置，未改动任何路线端点或原时间安排。

候选列表也可展开详情，不必先生成计划。成功详情缓存、串行与重试沿用现有机制。此次没有查询用户定位，没有调用路线 API。
