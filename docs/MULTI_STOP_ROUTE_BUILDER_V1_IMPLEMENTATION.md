## 独立边界

`既有默认单地点全量排序 → 只读Family视图 → 前两名免费预检 → 锁定Anchor → 有界两站验证 → 有界第三站准入 → 路线排序 → 去重 → 最多3条`

单地点先展示，多地点异步补充，两个独立结果区共用右侧行程单/复制功能。30分钟仅单地点；45/60最多2站；90–180休息最多2站、散步/探索最多3站。所有时长保留单地点。返程开启或骑行时，多地点明确不支持，不改变单地点。

没有修改单地点引擎、v3供给、Goal Match、Mobility、商户价格/评分排序、单地点停留、buffer或地图核心Contract。多地点只消费已经通过单地点门禁的候选，不额外Search/Detail，不补召回。

## 实际规则

- `policy.ts`：24条已确认祖先路径对应11个Family和既定dwell区间；UNKNOWN不猜测，不进入Multi-stop，原单地点不受影响。
- `builder.ts`：Anchor来自默认排序，不读取用户主动排序。全池免费扫描之后，只有首名完全无潜在两站组合才回退一次；不得尝试第三名。真实请求失败后不换Anchor。
- 免费扫描只用已有成功边作交通下界；未知边乐观按0进行潜力检查。几何不作为速度估算或硬否决。明确成功缓存可提前排除不可行组合。
- 技术提案顺序：路线最弱Goal等级、MST/chain、既有单地点排名；最多6个第二站、3个两站前缀、每前缀2个第三站。没有类别权重，没有Family配额或强制凑数。
- 全路段秒数之和接受既有open-ended Travel Gate（0.3T）、显式maxWalkingMinutes MUST以及总时间检查。沿用`bufferForBudget`。同Family、同POI不可重复，所有段必须有真实成功数据（mock测试除外）。不查返程。
- `math.ts`：从各min出发，按区间宽度同比例舒展，达到max后留余量。每次第三站准入重算所有站，但不低于min；保留两站草案共同竞争。UI停留向下取5分钟粒度，时间轴/合计/剩余均按同一displayDwell重算，交通内部仍保留秒数。
- 坐标投影到同一局部米制平面计算MST/chain；全重合为UNKNOWN；无角度/G硬门槛。G是几何信号，不是实际路网绕行证明。

## 排序与去重

1. 最弱Goal：S > M > W；同最弱等级再比较S占比。因此M+M胜S+W。
2. 同Goal质量组内按交通时间建立固定参照Mobility组：`travel < 1.2 * groupMinimum`，精确20%进入下一组，0只与0同组。
3. 组内G较高优先，UNKNOWN靠后。
4. 所有站评分已知才聚合min rating；双方>4.5转Price，否则严格比较；完整评分优先UNKNOWN。
5. 所有站商户价格已知才聚合算术平均；便宜优先，已知优先UNKNOWN。不是路线总消费，不把缺失当0。
6. 稳定identity。无站数/时间利用率奖励，无综合评分。

排序后：无序POI集合相同或包含、去Anchor后的Family集合相同或包含，均视为重复。最多3条，可只剩1条，不强制三种方案。

## 请求与缓存

`edges.ts`：有向key包含模式、坐标系、端点身份和坐标、destinationUid、入口策略版本。新增边缓存5分钟，最多128项逐条淘汰；run内在途合并及失败记忆，无自动重试。保留现有server固定代理、限速、共享缓存；不改旧客户端路线缓存。

起点到Anchor复用本次单地点输出中的同canonical端点成功路线，不额外调用起点边。它继承单地点已有来源/时效保证，**不把旧客户端Map任意条目包装成新鲜的多地点缓存**。

当前UI选保守实验budget=6；Builder允许显式6或12。三站模式首轮第二站提案为budget/2，即6时3个、12时6个，先给第三站留探索空间；完成首轮扩展后，未用额度归还剩余第二站队列，最多检查6个第二站、总共最多扩展3个前缀、每前缀2个第三站。不得因前3个第二站失败而闲置剩余请求。这不是最终实测定额。两站模式最多6个第二站。缓存命中不占本地请求预算，失败占预算，server缓存命中仍保守计作一次代理调用。

- 选定两站：最少新增1条A→B；三站：最少新增2条A→B、B→C；全命中0。
- 当前UI最坏新增6次，实验12配置最坏12次；免费回退不产生第一Anchor额外请求，不重置budget。
- 单地点之前的算路请求另计，不承诺全站总共6次。
- 修改条件/位置/Goal、重新生成或卸载会取消旧run，旧响应不回写，不再发后续请求。已发请求仍可能完成并计费；不声称取消能撤回provider调用。沿用底层每请求12秒超时。
- 排序、查看更多、选择行程、React rerender不会运行Builder。多地点验证期间生成按钮禁用，条件仍可修改以取消旧run。

## 结果与真实边界

`ok`；`not_applicable`；`unsupported_mode`；`no_feasible_multi_stop`（受前两名Anchor政策限定的免费证明）；`missing_candidate_facts`；`missing_offline_edges`；`provider_unavailable`；`search_incomplete`（budget/top-k未穷尽）；`no_route_for_anchor`（锁定Anchor的已检查组合不成立）。Provider明确no_route单独计数，不冒充服务故障。

公开区域65个历史地点仍只有起点去程，未编造站间路线，replay永远不联网。全文化Family返回免费无解；其余池理论可组而缺站间边时明确说明缺历史数据。旧mock UI没有可靠Goal元数据，不伪造等级；专用多Family纯合成测试fixture独立于这些真实历史案例。

尚未验证：6/12预算的真实质量收益、真实路线耗时/命中率、路网与直线几何差异。继承现有单地点已关闭过滤，但现有字符串营业字段不足以保证每站抵达时营业；不提供这种保证。低G只软比较，不能承诺杜绝所有折返。UI浏览器审核由用户进行，本轮仅测试SSR呈现，未操作真实页面。
